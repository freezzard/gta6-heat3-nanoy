Solara Heat — an open-world crime game in Leonida: steal the Comet GT, outrun 5-star police pursuits, run four chained heist missions for the Corvidae syndicate, and escape by boat at sunset on Ocean Drive.

## Run it

```sh
python3 -m http.server --directory game 8000
```

Then open http://localhost:8000 in desktop Chrome.

## Play

- **WASD** — move on foot, drive once behind the wheel.
- **F** — enter or exit the nearest car.
- **Mouse / click** — aim and shoot; **R** reloads.
- **P** — pause; **M** — mute the radio.
- **M1 — Courier Run:** deliver a package across Leonida for $250 and earn the Corvidae syndicate's trust.
- **M2 — Comet GT:** steal the golden Comet GT from its guarded spot and lose the cops.
- **M3 — Box Truck:** haul a box truck to the drop-off against the clock while the heat closes in.
- **M4 — Cash Drop:** grab three cash drops across the city, then shake a 5-star pursuit and escape by boat.
